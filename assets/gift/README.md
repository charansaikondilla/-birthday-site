# assets/gift/

Put the product image here as **`iphone.png`** (transparent PNG/WebP, ~600×800px, portrait).

- Configured in `script.js` → `birthdayConfig.gift.image`.
- If the file is missing, a clean CSS-drawn phone is shown instead.
- Set the model name and message in `birthdayConfig.gift`.

Note: this is a digital presentation of the gift, not a real delivery.
